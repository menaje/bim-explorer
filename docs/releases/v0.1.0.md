# BIM Explorer Community v0.1.0

This is the first account-free, local-first BIM Explorer Community release.

## Included

- read-only local IFC4 `ReferenceView_V1.2` exploration;
- bounded source snapshot, hierarchy, primitive properties, relations, search;
- WebGL2 3D camera, pick, isolate, section, measurement, and saved view;
- VS Code `.ifc` Custom Editor and standalone Browser surface;
- bounded BCF XML 3.0, IDS 1.0 result, and bSDD reference exploration source;
- optional authority-free Coni Spatial handoff contract;
- MPL-2.0 source, Apache-2.0 specifications, SPDX SBOM, SHA-256 checksums,
  cross-platform reproducible artifacts, and GitHub build attestations.

## Important limits

The admitted profile is experimental and read-only. This release does not
claim native authoring, write/round-trip, IFC2X3 or IFC4.3 admission, RVT/DGN
support, cloud collaboration, physical GPU qualification, native IDS
validation, paid support, warranty, or Coni Spatial Workspace authority.

gh attestation verify \

shasum -a 256 -c SHA256SUMS
