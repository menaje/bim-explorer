# Specifications

이 디렉터리의 versioned public contract, schema와 normative example은
구현 코드의 MPL-2.0과 별도로 [Apache License 2.0](LICENSE)으로
제공합니다. 각 문서의 `draft` 또는 `accepted` 상태는 라이선스와 별개의
호환성 수준입니다.

아직 accepted normative specification은 없습니다. package 이름, Viewer
Core protocol version, IFC implementation profile과 cache format은 관련 ADR,
schema와 valid/invalid fixture가 함께 준비되기 전 확정하지 않습니다.
