# Semantic explorer Browser probe

generated semantic IFC를 같은 immutable source session의 semantic query와
WebGL2 renderer에 연결하는 로컬 qualification surface입니다.

검증 범위는 spatial hierarchy, containment/decomposition 구분,
occurrence/type 왕복, Pset/Qto/material/classification panel, bounded
search와 omission, tree/search/property/3D selection sync, isolate,
saved view, keyboard tree navigation, accessible roles, bounded DOM,
resource cleanup입니다.

이 앱은 배포 제품이 아니며 `npm run probe:semantic`으로 localhost에서만
실행합니다.
